# Python Quiz Game (CLI)

A simple command-line quiz game built using Python.

## Features
- Multiple choice questions
- Score tracking (+1 for correct, -1 for wrong)
- Randomized questions
- Shows correct answer when wrong
- Displays final score and percentage
- Performance feedback
- Input validation
- Restart option

## Concepts Used
- Lists
- Dictionaries
- Loops
- Conditional statements
- Functions
- Random module
- User input handling

## How to Run

python quiz_game.py
